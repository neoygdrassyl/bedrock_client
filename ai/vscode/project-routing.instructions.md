# Routing Operativo Del Proyecto

Usa `AGENTS.md` y la carpeta `ai/` como fuentes canonicas de bootstrap y verdad operativa.

Regla corta:

- dominio, contratos, integraciones o arquitectura -> `ai/system-map.md`
- auth o sesion -> `ai/auth/session-contract.md`
- validacion y pruebas -> `ai/testing-runbook.md`
- cierre de release -> `ai/release-runbook.md`

Manten `.github/instructions/` enfocado en reglas de comportamiento o routing. No dupliques aqui la documentacion operativa larga.
